# 2026-06-23 宠物类型与预设品种来源审阅

## 结论

本次预设扩展优先选择有稳定 emoji 头像的动物类型，并用权威注册组织、兽医手册、大学扩展资料或专业宠物饲养指南交叉校准名称。猫、狗、兔、马、猪、鸡、牛、羊、山羊使用品种预设；鸟、仓鼠、鱼、龟、蛇、啮齿类在日常饲养中更常按物种、类型或品系记录，因此预设按“常见饲养类型”处理。

`PetType.other` 继续沿用用户自定义 `avatarText`，不映射动物 emoji。猴类虽然有 emoji，但不作为本轮预设类型：它不符合“常见宠物建档”的产品语义，且资料主要来自灵长类数据库而非宠物饲养指南。

## 维护边界

- 不把“其他”迁移到任何新增类型，避免破坏旧数据和用户自定义头像缩写。
- 不把物种名伪装成严格品种名；鸟、鱼、龟、蛇、啮齿类后续如要改 UI 文案，应考虑“常见类型”而不是“常见品种”。
- 新增类型只扩展本地 enum 和 JSON name，不改同步协议字段形状；旧客户端读取未知类型仍会降级为 `other`。
